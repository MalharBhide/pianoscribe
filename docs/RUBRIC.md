# Arrangement listening rubric (fixed, v1)

Use for every song-to-piano candidate. Rate 1–5 (1 poor … 5 excellent):

1. **Melody recognizability** — can a listener name/follow the tune?
2. **Harmonic plausibility** — do LH voicings fit the recording's harmony?
3. **Playability** — two hands, no impossible stretches or collisions?
4. **Clutter** (reverse-scored: 5 = clean) — unsupported extra notes?
5. **Rhythm readability** — beats/bars feel right against the recording?

Procedure: 3+ raters, blind to version, same 5 reference excerpts + 2 held
out. Report median + range per item; gate threshold applies to the median
of items 1–3 and item 4 separately. Multiple voicings can score 5 — judge
against the RECORDING, never against a single reference arrangement.
